# hrs-test-package

Публичный тестовый пакет harness. Содержит один скилл `review`.
Не содержит учётных данных или исполняемых скриптов. Лицензия MIT.

Установка:

```sh
hrs package add https://github.com/gromovart/hrs-test-package.git --workspace SPACE --project PROJECT --agent codex
```

Замените SPACE и PROJECT именами выбранного пространства и проекта.
После установки перезапустите агента и явно выберите скилл `review`.
